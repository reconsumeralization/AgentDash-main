## 🔐 API Permissions

The Profile API requires specific permissions based on the data you need:

### Permission Levels

| Permission | Description | Required Fields |
|------------|-------------|-----------------|
| `r_liteprofile` | Basic profile information | Name and photo |
| `r_basicprofile` | Extended profile information | Name, photo, headline, vanity name |
| `r_compliance` | Private permission for compliance | Activity monitoring and archiving |

### Permission Implementation

```typescript
import { ProfilePermission } from '@/lib/linkedin-profile-api'

// Check if profile has required permissions
const hasBasicProfile = LinkedInProfileUtils.hasPermission(profile, ProfilePermission.BASIC_PROFILE)
```

## 🏗️ Implementation

### Core API Client

The `LinkedInProfileApi` class provides the main interface for interacting with the LinkedIn Profile API:

```typescript
import { LinkedInProfileApi } from '@/lib/linkedin-profile-api'

const profileApi = new LinkedInProfileApi(accessToken)

// Get current member's profile
const profile = await profileApi.getCurrentMemberProfile()

// Get another member's profile
const memberProfile = await profileApi.getMemberProfile('person-id-123')

// Get multiple profiles
const profiles = await profileApi.getMultipleMemberProfiles(['id1', 'id2', 'id3'])
```

### API Endpoints

Based on the LinkedIn documentation, the following endpoints are supported:

#### Current Member Profile
```
GET https://api.linkedin.com/v2/me
```

#### Other Member Profile
```
GET https://api.linkedin.com/v2/people/(id:{person ID})
```

#### Multiple Member Profiles
```
GET https://api.linkedin.com/v2/people?ids=List((id:{Person ID1}),(id:{Person ID2}))
```

#### Field Projections
```
GET https://api.linkedin.com/v2/me?projection=(id,firstName,lastName)
```

#### Geo Location with Decoration
```
GET https://api.linkedin.com/v2/me?projection=(geoLocation(geo~,autoGenerated))
```

## 📖 Usage Examples

### Basic Profile Retrieval

```typescript
import { useLinkedInProfile } from '@/lib/linkedin-profile-api'

function ProfileComponent() {
  const { profile, loading, error, fetchCurrentProfile } = useLinkedInProfile(accessToken)

  useEffect(() => {
    if (accessToken) {
      fetchCurrentProfile()
    }
  }, [accessToken, fetchCurrentProfile])

  if (loading) return <div>Loading profile...</div>
  if (error) return <div>Error: {error.message}</div>
  if (!profile) return <div>No profile data</div>

  return (
    <div>
      <h1>{profile.localizedFirstName} {profile.localizedLastName}</h1>
      <p>{profile.localizedHeadline}</p>
    </div>
  )
}
```

### Advanced Profile Operations

```typescript
import { LinkedInProfileApi, LinkedInProfileUtils } from '@/lib/linkedin-profile-api'

async function advancedProfileOperations() {

  const isMigrated = profileApi.isLocationMigrated(profile)

  // Format profile for display

}
```

### Multiple Profile Management

```typescript
function MultipleProfilesComponent() {
  const { fetchMultipleProfiles, loading } = useLinkedInProfile(accessToken)

  const handleFetchMultiple = async () => {
    const personIds = ['id1', 'id2', 'id3']
    const profiles = await fetchMultipleProfiles(personIds)
    
    profiles.forEach(profile => {
      console.log(`Profile: ${profile.localizedFirstName} ${profile.localizedLastName}`)
    })
  }

  return (
    <button onClick={handleFetchMultiple} disabled={loading}>
      Fetch Multiple Profiles
    </button>
  )
}
```

## 🏷️ Type Definitions

### Core Profile Types

```typescript
interface LinkedInProfile {
  id: string                    // Person ID - unique identifier
  firstName: MultiLocaleString  // First name with localization
  localizedFirstName: string    // Localized first name
  lastName: MultiLocaleString   // Last name with localization
  localizedLastName: string     // Localized last name
  headline?: MultiLocaleString  // Professional headline
  localizedHeadline?: string    // Localized headline
  vanityName?: string          // Vanity name for public URL
  profilePicture?: {           // Profile picture information
    displayImage: string       // URN to profile picture
  }
  geoLocation?: GeoLocation    // New geo location data
  location?: LegacyLocation    // Legacy location data
}
```

### Location Types

```typescript
interface GeoLocation {
  geo: string                  // URN to geo location
  autoGenerated: boolean       // Whether location is auto-generated
  'geo~'?: {                  // Decorated geo data
    id: number
    defaultLocalizedName: {
      locale: Locale
      value: string
    }
  }
}

interface LegacyLocation {
  postalCode?: string
  standardizedLocationUrn?: string
  userSelectedGeoPlaceCode?: string
  countryCode?: string
}
```

```typescript

if (LinkedInProfileUtils.hasPermission(profile, ProfilePermission.BASIC_PROFILE)) {
```

## 🚨 Error Handling

### Common Error Scenarios

1. **Authentication Errors (401)**
   - Invalid or expired access token
   - Missing authorization header

2. **Permission Errors (403)**
   - Insufficient permissions for requested data
   - Member has restricted profile visibility

3. **Not Found Errors (404)**
   - Invalid person ID
   - Member profile not accessible

4. **Rate Limiting (429)**
   - Too many API requests
   - Implement exponential backoff

### Error Handling Implementation

```typescript
import { useLinkedInProfile } from '@/lib/linkedin-profile-api'

function ProfileWithErrorHandling() {
  const { profile, loading, error, fetchCurrentProfile } = useLinkedInProfile(accessToken)

  const handleRetry = () => {
    fetchCurrentProfile()
  }

  if (error) {
    return (
      <div className="error-container">
        <h3>Error Loading Profile</h3>
        <p>{error.message}</p>
        <button onClick={handleRetry}>Retry</button>
      </div>
    )
  }

  // ... rest of component
}
```
