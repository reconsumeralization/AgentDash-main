## Breaking Changes

### Version 2.1.0 Breaking Changes

#### API Changes
- **Authentication**: Updated JWT token format (requires re-authentication)
- **Webhooks**: Changed webhook payload structure
- **Rate Limits**: Updated rate limiting headers and responses

#### Database Changes
- **Schema Updates**: New required fields in user profiles
- **Data Migration**: Automatic migration for existing users
- **Index Changes**: Updated database indexes for performance

#### Configuration Changes
- **Environment Variables**: New required environment variables
- **SSL Configuration**: Updated SSL/TLS requirements
- **Firewall Rules**: Updated firewall configuration requirements

### Migration Guide

#### API Migration
```bash
# Update API client
npm install @defconect/sdk@latest

# Update authentication
const client = new DefConectClient({
  apiKey: process.env.DEFCONECT_API_KEY,
  version: '2.1.0'
})
```

#### Database Migration
```bash
# Run database migrations
npm run db:migrate

# Verify migration
npm run db:verify
```

#### Configuration Update
```bash
# Update environment variables
export DEFCONECT_API_VERSION="2.1.0"
export DEFCONECT_SSL_REQUIRED="true"
export DEFCONECT_AUDIT_LOGGING="enabled"
```
